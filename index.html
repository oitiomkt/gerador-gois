Gerador de Anúncio de Carga

Preencha os campos e baixe a imagem pronta para WhatsApp/Instagram.

📱 iPhone: se o botão "Compartilhar" não aparecer aqui em cima, você provavelmente está numa pré-visualização rápida do arquivo, não no Safari de verdade. Toque no ícone de compartilhar do iOS (fora desta página) e escolha "Safari" para abrir esta página numa aba normal — aí os botões funcionam.

Este gerador roda 100% no seu computador — nada é enviado para a internet (apenas a fonte Exo 2 é carregada do Google Fonts na primeira vez que a página abre). No celular, use o botão "Compartilhar" para enviar direto pelo WhatsApp — é mais confiável do que "Copiar". Se abrir o arquivo pelo visualizador do WhatsApp (ícone de anexo), o "Copiar" pode ser bloqueado pelo sistema; baixe/abra o arquivo direto no navegador para evitar isso.

Pré-visualização em tempo real. A imagem baixada sai em alta resolução (1080×1920), ideal para Status do WhatsApp e Stories.
